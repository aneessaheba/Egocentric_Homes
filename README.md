# EgoLoop

EgoLoop is a data collection platform for egocentric household activity footage. Contributors record everyday tasks from a first-person perspective and submit clips through competitions for cash prizes. The resulting data powers robotics and Physical AI research.

**Live site:** [aneessaheba.github.io/Egocentric_Homes](https://aneessaheba.github.io/Egocentric_Homes) · **Contact:** aneessaheba04@gmail.com

## Dataset — HomeHands-50

The core dataset: egocentric RGB footage of everyday household activities captured from a first-person wearable camera. The foundation for all derived annotation layers below.

| Metric | Value |
|---|---|
| Hours | 50 |
| Videos | 2,700 |
| Frames | 5.4M |
| Tasks | 25 |
| Action classes | 100 |
| Narrations | 7,600 |
| Hands tracked | 1.8M |
| Segmentation masks | 8.9M |

Example activities: washing a cup, cutting a banana, folding clothes, making tea, mopping, sweeping, arranging shoes, pouring water, and more.

## Derived Datasets

Each derived dataset adds an annotation layer generated by running raw footage through the pipeline.

### HomeTrace — Hand Tracking

![HomeTrace sample](assets/preview_hometrace.gif)

21-point hand skeleton (wrist, knuckles, and fingertips) tracked per frame for both hands using MediaPipe HandLandmarker. Outputs x, y, z coordinates per keypoint.

- **Detection rate:** 82% · **Keypoints:** 21 · **Hands:** 2 · **Format:** JSON

### HomeMask — Segmentation

![HomeMask sample](assets/preview_homemask.gif)

Per-frame instance masks for hands, objects, and surfaces using a SAM2.1 Hiera-Tiny model prompted by hand bounding boxes. Binary PNG masks across 20 classes.

- **Masks/frame:** 4 · **Classes:** 20 · **Format:** Binary PNG

### HomeVoice — Audio Narration

![HomeVoice sample](assets/preview_homevoice.gif)

Live-narrated recordings where the contributor describes their own actions in real time, transcribed with Whisper. Outputs SRT subtitles and timestamped narration JSON.

- **Clips:** 2,700 · **Sentences:** 7,600 · **Format:** JSON + SRT

## Annotation Pipeline

Raw video goes through six automated stages before a human sees it. The full pipeline is run with a single command.

```
Raw GoPro Video
      ↓
┌─────────────┬─────────────┬───────────────┬──────────────┬───────────────┬──────────────┐
│  Hand Pose  │  Arm Pose   │ Segmentation  │    Depth     │ Transcription │ Quality Gate │
│      ↓      │      ↓      │       ↓       │      ↓       │       ↓       │      ↓       │
│Keypoints JSON│  Arm JSON  │SAM2 Masks(PNG)│Depth PNGs   │ Narration JSON│Quality Report│
└─────────────┴─────────────┴───────────────┴──────────────┴───────────────┴──────────────┘
                                                                                    ↓
                                                                          Combined Full JSON
```

> Clips scoring below **60** on the quality gate are moved to `assets/videos/rejected/` — never deleted.

### Pipeline Modules

| Module | Script | Model | Output |
|---|---|---|---|
| Hand Pose | `pipeline/hand_pose.py` | MediaPipe Hand Landmarker | `hand_pose.json` per clip |
| Arm Pose | `pipeline/arm_pose.py` | YOLOv8n-pose (Ultralytics) | `arm_pose.json` per clip |
| Segmentation | `pipeline/segmentation.py` | SAM2.1 Hiera-Tiny (Meta AI) | Binary mask PNGs per clip |
| Depth | `pipeline/depth.py` | Depth-Anything-V2-Metric-Indoor-Small | 16-bit depth PNGs per clip |
| Transcription | `pipeline/transcribe.py` | OpenAI Whisper base | `.srt` + `narration.json` + subtitled `.mp4` |
| Quality Check | `pipeline/quality_check.py` | MediaPipe + Whisper | Quality report JSON (0–100 score) |
| Quality Gate | `pipeline/quality_gate.py` | — | Rejects clips scoring < 60 |
| Full Pipeline | `pipeline/run_pipeline.py` | All of the above | Combined annotation JSON per clip |

## Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/aneessaheba/Egocentric_Homes
cd Egocentric_Homes

# 2. Install dependencies
pip install -r requirements.txt
brew install ffmpeg

# 3. Add your videos
cp your_videos/*.mp4 assets/videos/

# 4. Run the full pipeline
python pipeline/run_pipeline.py
```

**Output per video:**

```
assets/processed/hand_pose/       ← Hand keypoints JSON
assets/processed/arm_pose/        ← Arm segment JSON
assets/processed/masks/           ← Segmentation PNGs
assets/processed/depth/           ← 16-bit depth PNGs
assets/processed/narrations/      ← Narration JSON + SRT
assets/processed/quality/         ← Quality report JSON
assets/videos/rejected/           ← Clips that scored < 60
assets/processed/annotations/     ← Combined full JSON
```

## Website

The `*.html` files at the root are a static site for the EgoLoop platform. Built with Tailwind CSS v4 (CDN) and Font Awesome 6.5.2.

| Page | File | Description |
|---|---|---|
| Landing | `index.html` | Hero, What's Happening cards, Record section |
| Competitions | `campaigns.html` | Full campaign detail — Kitchen Activities Collection |
| Datasets | `dataset.html` | HomeHands-50 stats, derived dataset previews |
| Models | `pipeline.html` | Pipeline diagram, tool cards, quick start, model table |
| Sign In / Register | `auth.html` | Local-storage backed auth (dev only, no real backend) |
| Contributor Profile | `contributor.html` | Sample contributor stats and submission history |

To run locally:

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```
